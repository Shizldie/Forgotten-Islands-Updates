# Forgotten Village — beta builds

This repository only holds the finished builds that testers' phones download. The game's source lives elsewhere.

## Install (Android)
1. On your phone, download the app: **[forgotten-village.apk](https://github.com/Shizldie/Forgotten-Islands-Updates/raw/main/forgotten-village.apk)**
2. Open the downloaded file. If Android asks, allow your browser or file manager to **install unknown apps**, then tap **Install**.
3. Open **Forgotten Village** and start a village.

## Getting updates
You don't need to reinstall for new versions. The game checks for updates by itself when it opens, and you'll see a message when one is ready.
To check by hand: tap the **gear** (top right) > **Updates** > **Check for updates** > **Download update** > **Restart to finish**.
Your villages are kept through updates.

## Reporting problems
Tell the developer what you were doing, what happened, and your phone model. Screenshots help.

Files here: `forgotten-village.apk` (the app), `forgotten-village.html` + `version.json` (what the Update button downloads).
